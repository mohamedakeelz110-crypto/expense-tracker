# 💸 Expense Tracker

A simple, responsive expense/budget tracker web app that helps you log daily expenses, set a monthly budget, and visualize spending with an interactive pie chart.

🔗 **Live Demo:** https://mohamedakeelz110-crypto.github.io/expense-tracker/

## Features
- Add, view, and delete expenses with category, amount, date, and notes
- Set a monthly budget and track remaining balance in real time
- Interactive pie chart showing budget allocation vs. spending by category (built with Chart.js)
- Data persists automatically using browser localStorage — no backend needed
- Fully responsive, mobile-friendly design with light/dark mode support

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- [Chart.js](https://www.chartjs.org/) for data visualization
- Browser localStorage for data persistence

## How to Run Locally
1. Clone or download this repository
2. Open `index.html` in any browser — no build steps or dependencies required
